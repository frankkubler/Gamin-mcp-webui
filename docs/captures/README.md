# Captures d'écran du guide utilisateur

Ce dossier reçoit les captures que
[connecter-garmin-a-claude.md](../connecter-garmin-a-claude.md) référence pour les
écrans **côté Claude**. Elles ne peuvent pas être produites depuis ce dépôt : ce sont
des écrans de claude.ai et de Garmin, pas des pages servies par ce serveur.

| Fichier attendu | Écran |
| --------------- | ----- |
| `01-menu-connecteurs.png` | Customize > Connectors |
| `02-ajouter-connecteur.png` | le bouton « Add custom connector » |
| `03-formulaire-url.png` | le formulaire nom + URL du serveur MCP |
| `04-oauth-client.png` | le réglage « Use your own OAuth client » |
| `05-login-garmin.png` | la page de connexion Garmin |
| `07-autorisations.png` | les autorisations des outils du connecteur |
| `08-activer-conversation.png` | l'activation du connecteur dans une conversation |

Les deux écrans servis par le déploiement lui-même — le consentement et la mise en
attente — sont dans le dossier parent (`docs/consentement.png`, `docs/en-attente.png`)
et sont régénérés à partir des pages réelles quand elles changent.
