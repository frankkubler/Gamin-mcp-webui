# Captures d'écran du guide utilisateur

Ce dossier reçoit les captures que
[connecter-garmin-a-claude.md](../connecter-garmin-a-claude.md) référence pour les
écrans **côté Claude** : des écrans de claude.ai, qui ne peuvent pas être produits depuis
ce dépôt.

| Fichier attendu | Écran |
| --------------- | ----- |
| `01-menu-connecteurs.png` | Customize > Connectors |
| `02-ajouter-connecteur.png` | le bouton « Add custom connector » |
| `03-formulaire-url.png` | le formulaire nom + URL du serveur MCP |
| `04-oauth-client.png` | le réglage « Use your own OAuth client » |
| `05-login-garmin.png` | l'annonce et le formulaire d'identifiants Garmin — **servis par ce déploiement** : à refaire quand ces pages changent |
| `07-autorisations.png` | les autorisations des outils du connecteur |
| `08-activer-conversation.png` | l'activation du connecteur dans une conversation |

Les deux autres écrans servis par le déploiement lui-même — le consentement et la mise
en attente — sont dans le dossier parent (`docs/consentement.png`, `docs/en-attente.png`)
et sont régénérés à partir des pages réelles quand elles changent. `05` appartient à la
même catégorie malgré son emplacement ici : c'est le seul de ce dossier qui vieillit
quand les pages du login bougent.
